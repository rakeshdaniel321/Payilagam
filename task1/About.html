Project Overview

This project is a personal portfolio website created to showcase my skills, projects, social profiles, and contact information. The website is designed using HTML5 and CSS3, with Web Awesome icons integrated to make the navigation and interface more attractive and user-friendly.

The main purpose of this portfolio is to provide a simple and professional way to introduce myself, display my technical skills, showcase my projects, and provide links to my GitHub, LinkedIn, LeetCode, and Dev.to profiles.

Technologies Used

  • HTML5 – Used to create the structure and content of the portfolio.
  • CSS3 – Used for styling, colors, spacing, layouts, hover effects, and responsive design.
  • Web Awesome – Used for adding scalable icons to the website.
  • Font Awesome – Used as the icon source/library for the icons available through Web Awesome.
  • Media Queries – Used to create different layouts for desktop and mobile screens.

Icons Used in the Project

Mobile Layout

The mobile layout is designed for smaller screen sizes such as smartphones.

In the mobile view, the navigation links are replaced with icons and displayed vertically on the side of the page. This makes the navigation compact and easier to access on a smaller screen.

The sections are also kept within a suitable width so that the content remains readable without requiring unnecessary horizontal scrolling.

Desktop Layout

For desktop screens, the website uses a wider layout with more available screen space.

When the screen width reaches 1200px or more, a CSS media query changes the appearance of the website. The desktop navigation links become visible, while the mobile icon navigation is hidden.
